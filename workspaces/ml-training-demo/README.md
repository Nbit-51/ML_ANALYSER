# ML Training Demo

This is a small, executable binary classification repository. `train.py` fits logistic regression from `train.csv`, evaluates the held-out `validation.csv`, and writes observed metrics. The hidden failure is an almost zero learning rate and one training epoch. The manifest proposes a candidate training configuration. ML Analyser measures both copies, evaluates the success contract, and retains only the accepted candidate copy.

This fixture is intentionally dependency free so the full local workflow is reproducible without a GPU or Nebius token. It proves the bounded training adapter, not arbitrary ML framework support.
