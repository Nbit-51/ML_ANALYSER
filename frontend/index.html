REPOSITORY ANALYSIS

Analyse an ML repository

Choose any local repository folder inside workspaces/. The preview inventories files, reads a few relevant excerpts and prior result records, and proposes tests. It does not run project code.

With the Nebius provider enabled, sampled repository excerpts and result records are sent to Nebius for reasoning. Do not preview a private repository until you are comfortable sharing those excerpts. Model proposals may contain unsupported implementation details; verify the cited code before acting.

How to read the goal

The objective is the score you want to improve. A target is the desired value. A guardrail is a limit another score must respect. A proposal becomes a measured improvement only after a compatible experiment runs.
