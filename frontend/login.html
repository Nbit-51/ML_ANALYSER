Connect your GitHub OAuth app

  1. Create an OAuth app in GitHub Developer settings.
  2. Set its homepage to this app's origin and its callback to:
  3. Add these settings to your local .env, then restart the server:
ML_ANALYSER_APP_URL=http://127.0.0.1:8000
ML_ANALYSER_GITHUB_CLIENT_ID=your-client-id
ML_ANALYSER_GITHUB_CLIENT_SECRET=your-client-secret
ML_ANALYSER_GITHUB_ALLOWED_USERS=your-github-login

Keep the secret in .env. Only listed accounts may sign in. GitHub sign-in requests public identity only; it does not grant access to private repositories. Use HTTPS when serving beyond localhost.
