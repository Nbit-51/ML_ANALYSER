PRICING CACHE EXAMPLE

Reuse prices without mixing them up.

The same product can have different prices for each organization and currency. This example checks whether a cache reduces calculations while keeping those prices correct.

Goal
Fewer price calculations ↓ Lower is better
Required check
Every price must match Compared with the uncached result
Run limit
Up to 3 configurations Each compared 3 times
About this example

Tests use generated pricing queries and the included Python cache. Only cache-key settings change. Calculation counts describe work performed in this example; they do not measure response time or cost savings.
